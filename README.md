# Careflow - Healthcare Appointment & Patient Management System

Careflow is a modern, cross-platform healthcare management system built with **Flutter** and **Firebase**. It provides a unified digital experience for three primary healthcare roles: **Patients**, **Doctors**, and **Administrators**.

---

## 🌟 Key Features

### 🏥 Patient Workspace
- **Smart Appointment Booking**: Select doctor, department specialty, date & time slot, and specify visit symptoms.
- **My Appointments Queue**: View live appointment status (`Confirmed`, `Pending`, `Completed`, `Cancelled`) with one-click cancellation.
- **Care Team Directory**: Catalog of hospital specialists (*Cardiology, Dermatology, Pediatrics, Neurology*) with ratings and experience.
- **Health Records**: View medical history, lab reports, and active prescriptions.

### 🩺 Doctor Workspace
- **Clinical Schedule**: Daily appointment queue with one-touch approval workflows (`Approve`, `Complete`).
- **Patient Chart Directory**: Access patient demographics, blood group, age, gender, chronic conditions, and medication history.
- **Clinical Documentation**: Add diagnoses, clinical notes, and prescription instructions.

### ⚙️ Administrator Control Center
- **Operations Dashboard**: System performance metrics (*Total Patients, Active Staff, System Appointments*) and real-time security audit feeds.
- **Medical Staff Onboarding**: Register new doctors to hospital staff with custom specialties.
- **Patient Registry**: Manage global patient database and add walk-in admissions.
- **Analytics & Reports**: Platform metrics, satisfaction ratings, and system uptime logs.

## 🚀 Technology Stack

- **Frontend**: Flutter SDK (Dart)

- **Database**: Cloud Firestore (Real-time NoSQL)
- **Design System**: Material Design 3

## 💻 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ronak-uh/itm-flutter-miniproject-healthcare-appointment-patient-management-system-10-09-2026.git
   cd itm-flutter-miniproject-healthcare-appointment-patient-management-system-10-09-2026
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run on Chrome (Web)**:
   ```bash
   flutter run -d chrome
   ```

4. **Build Web Production Bundle**:
   ```bash
   flutter build web
   ```
